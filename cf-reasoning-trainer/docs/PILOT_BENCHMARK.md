## Mechanisms and finite references

| Family | Intended reasoning to examine | Small-domain oracle |
| --- | --- | --- |
| Packet removal | Per-pile invariants; necessary and sufficient conditions; construction | Enumerate reachable sizes by legal removals |
| Equal piles | Global conservation, surplus lower bound, transport construction | Enumerate conserved final height; direct surplus/distance reference |
| Window toggle | Forced leftmost decision, parity cancellation, final suffix | Breadth-first search of all reachable bit states |
| Subarray residue | Prefix-difference correspondence, empty prefix | Enumerate all subarrays |
| Reverse machine | Disjoint reverse predecessors and monotonic process | Forward breadth-first search to the bounded target |
| Interval packing | Earliest-finish exchange proof, endpoint semantics | Enumerate interval subsets and check pairwise nonoverlap |
| Spaced selection | Sufficient prefix state; largest-value greedy counterexample | Enumerate subsets and test index distances |
| Circular selection | Boundary-dependent state and linked observations | Enumerate subsets and check cyclic runs |
| Subset residue | State compression, simultaneous DP update, counting positions | Enumerate position subsets |
| Minimax partition | Bound feasibility, nonnegative extension, monotonicity | Enumerate every set of cuts |
| Rotation mismatch | Allowed transformation versus arbitrary permutation | Enumerate rotations and exact mismatches |
| Residue pairs | Equivalence classes, ordered versus unordered pairs | Enumerate ordered pairs |
| Zero XOR cuts | Total invariant plus eligible internal boundaries | Enumerate cuts and compute each segment XOR |
| Cover points | Leftmost extremal anchor and construction | Enumerate candidate interval-start subsets |
| Cancel runs | Local cancellation, emerging adjacency, normal-form proof obligation | Recursively explore every legal deletion with memoization |

These are authored reference ideas, **not independently reviewed gold labels**. `referenceForReviewOnly` is never included in Stage A/B/C model inputs or first-pass blind packets. Human reviewers can inspect source notes after making their independent judgments. The interval-cover reference relies on an anchoring lemma; equal-pile transport uses a formula after conservation rather than exhaustive transfer sequences. Those assumptions need review along with all other oracles.

Misleadingly similar pairs include packet removal versus equal-pile transfer, subarray versus subset residue counting, interval packing versus point covering, and rotation mismatch versus arbitrary sorting. Require reviewers to explain the mathematical difference rather than share an algorithm tag. Multi-observation cases include circular selection, minimax partition, window toggle and zero-XOR cuts. Simple code does not justify an easy discovery score.

Most statement lengths permit up to 200,000 elements and values up to 1,000,000,000; rotation mismatch permits 2,000 elements, and the reverse machine targets up to 10^12. Counting subsets/cuts uses modulus 1,000,000,007. Inputs are JSON integer arrays for the bounded harness. Oracle tests use at most eight elements and values at most five (bits where required), or targets at most 200. Four named boundary cases and 64 seeded random cases supplement each sample. Full-scale complexity and proof are separate human obligations.

Default seed is 1729. The manifest, parameter, oracle, prompt and output schema hashes are pinned in each run. Reproducibility means identical inputs, test generators and evaluation rules; live model responses may still vary. Never train prompts against these 45 cases and then call success on the same set unbiased generalization.

## Replacement by a real pilot

After permissions are established, select five distinct problems in each official band using the current catalog, freeze exact stable CF IDs and ratings, obtain permitted complete statements, and review a rights manifest. Select multiple families per band, include the mechanisms above and contrast pairs, and avoid near-duplicate tasks. Develop/review statement-specific oracles and bounded execution support, or explicitly record unsupported categories. Version the benchmark and its plan; original fixtures stay as regression tests. The present CLI rejects IDs outside its compiled original manifest, so registering a CF statement alone cannot trigger an evaluation.
